# ⚡ PokeDek - Interactive Pokémon Encyclopedia

A responsive, lightweight Pokédex web application built to search, discover, and inspect Pokémon attributes, stats, and artwork in real time.

🔗 **Live Demo:** [https://faisal12345-hash.github.io/PokeDek/](https://faisal12345-hash.github.io/PokeDek/)
## 🚀 Features
- **Instant Search:** Find Pokémon instantly by name or ID.
- **Type Filtering:** Filter the collection dynamically by element/type (Fire, Water, Grass, etc.).
- **Detailed Pokémon Profiles:** View high-resolution artwork, types, base stats, and bio descriptions.
- **Fully Responsive:** Optimized for both mobile devices and desktop screens.
- **Zero Dependencies:** Pure vanilla HTML5, CSS3, and JavaScript integration with the PokéAPI.
---
## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Data Source:** [PokéAPI](https://pokeapi.co/)
- **Hosting:** GitHub Pages
